# GAMER FEST ESPE 2027

Landing page responsiva (Mobile First) de un evento gamer universitario hipotético, creada con HTML5 y Bootstrap 5.3 como práctica de Programación Web. Los datos de fecha, premios y auspiciantes son demostrativos.

## Cómo abrirlo

1. Descarga o clona el repositorio.
2. Abre `index.html` en un navegador moderno (Chrome, Edge o Firefox).

## Dependencias que requieren Internet

- Bootstrap 5.3 (estilos y script del menú), cargado desde jsDelivr.
- Bootstrap Icons (iconos de redes sociales del pie de página), cargado desde jsDelivr.
- Mapa de Google Maps del campus Belisario Quevedo. Si no carga, la página muestra la descripción de la ubicación y un enlace alternativo.

## Estructura

```
gamerfest/
├── index.html
├── README.md
└── imagenes/
```

## Secciones

Encabezado con menú, inicio, categorías, premios, auspiciantes (simulados), ubicación, inscripción y pie de página.

## Estado del proyecto

- El espacio de inscripción está reservado: el formulario, sus validaciones y su confirmación se desarrollan en una etapa posterior (RF-06, RF-07 y RF-08).
- No se usa CSS ni JavaScript propios; el diseño se logra solo con clases de Bootstrap.
- Los enlaces de Instagram, Facebook y TikTok son demostrativos.

## Verificación

Diseñado para anchos de 375 px (móvil) y 1440 px (escritorio). Pasos para comprobarlo: abrir las herramientas del navegador (F12) y activar la vista de dispositivos.
